# Time and parallel work

The shaping has a {{budget}}-minute budget for all rounds together. Each round's text states the elapsed and remaining time. Plan to submit a complete package in the first round, well inside the budget, and use later rounds only to answer Kogen's feedback.
Issue independent reads, searches and commands together rather than one at a time.
For broad reading across many files, you may run several read-only subagents in parallel on a fast model (for example Sonnet or Haiku) and ask each for the specific facts you need, with file and line references; write the package itself in the main session. Do not use subagents for small lookups the main session can do directly.
Read what the request and its acceptance need, not the whole repository; stop exploring once the package can be written.
