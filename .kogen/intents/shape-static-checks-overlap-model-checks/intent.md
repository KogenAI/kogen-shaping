# Overlap static checks with model checks

Slug: shape-static-checks-overlap-model-checks
Model: not applicable — reschedule existing independent gates without introducing a domain state machine or changing gate policy

In shape/checkorder.go, change postSubmitChecks so that after the review scope and step self-check have not refused, the configured static checks and runModelChecks start together and both are awaited. Replace the sequential wait with overlapping execution: the round should take approximately the longer wait rather than their sum. Keep this a narrow Go scheduling change plus focused shape-package regression coverage beside shape/static_test.go or shape/advisory_gates_test.go. No browser, Rails or Studio work, new configuration, gate-policy changes or refusal-text changes.

Scope and step-self-check refusals continue to avoid model calls. A static refusal still discards model answers: no decision, literal or example gate result/refusal is reported for that package, and no assumption marks, advisory notes or remembered statement refusals from those discarded answers may affect later handling. Wasted model calls on statically refused candidates are intentional; retain honest transport usage accounting. Hold and publish surviving gate results/refusals in fixed order: static, decision, literal, example. Preserve feedback bytes, refusal grouping, held-refusal order and once-per-submission retry accounting. Await all work on every return; a model-check error cancels the static run, with the first error returned as runModelChecks already does. Do not introduce unsynchronised sharing of progress output, sh.ev events or the held-refusal batch. Preserve unchanged-candidate static-result reuse and base-tree reuse without weakening attribution or checks.

Add a focused, model-free regression test in the shape package using its existing scripted shaper helpers. Exercise a real configured sleeping check with an observable completion marker and an equally delayed scripted decision answer, and establish a clear margin below their summed waits for one post-submit submission. Also exercise a configured check failing specifically on the shaped step file, with deliberately refusing scripted model answers: only the static refusal survives. Update the existing assertion that static refusal makes zero model calls, because this request explicitly supersedes it; keep its useful checks that no model gate answers or refusals are reported. Keep existing cancellation, refusal-text, retry, passing-submission and reuse tests useful and passing. Acceptance independently overlays an owned observation test into the real shape package rather than depending on any unwritten Build test name.

## Decisions
- Overlap only after scope and step-self-check eligibility; static refusal discards model answers, whereas model errors cancel static execution and return the first error. (source: request)
- Preserve existing gate outcomes and all refusal text, fixed static/decision/literal/example publication order, retry accounting and both forms of static reuse; add no configuration. (source: request)
- Reuse the local scripted provider and shape fixtures for model-free regression and acceptance; compile an independent observation test into the real shape package with a Go overlay. (evidence: shape/helper_test.go; shape/shaping_fixture_test.go; shape/checkorder_test.go) (source: request)
- Replace the old zero-model-call assertion on static refusal with discarded-answer coverage; keep its static-only refusal and absent-model-event checks. (evidence: shape/checkorder_test.go) (source: request)
