# Tell the shaper the forms its gates require

Slug: k-shape-prompt-states-gate-forms
Model: not applicable — prompt text and checks of one submission; the only state is the existing accumulated proposals
Acceptance:
- .kogen/intents/k-shape-prompt-states-gate-forms/acceptance.feature

- features/steps/k-shape-prompt-states-gate-forms__harness.js

Shaping names, before the first submission, every form that its own gates require, so an ordinary small request is not refused for forms the shaper could not know. Three gates also accept exactly what the request asks them to accept: a marker anywhere on the line that holds a checked decision statement, an evidence item that starts with tracked paths followed by prose, and a bounded number of small files under the Intent's own folder. No gate accepts anything else that it refuses today; every refused case in the acceptance stays refused.

Owner files: `shape/prompts/shaper.md`, `shape/decision.go`, `shape/evidencemark.go`, `shape/shape.go` and the prompt goldens under `shape/testdata` (`shaper_policy_golden.json`, `prompts_golden.json`, `force_ordinary_golden.json`). The existing tests that quote the old "shaping may write only" line or the old prompt are updated with the change. The replacement of the intent.md template's prose line is stated in the Decisions.

The acceptance harness (`features/steps/k-shape-prompt-states-gate-forms__harness.js`) compiles into the shape package's tests through a Go overlay and uses the scripted-provider fixture of `shape/helper_test.go` (`newShpFx`, `shpAnswer`, `shpCall`, `shpSubmit`, `shpFiles`, `shpOutputs`, `shpScopedIntentMD`, `shpFeature`, `shpSteps`, `decisionRequest`, the fixture's `write`, `git`, `setReport`, `shape` and the provider's `route`, `requests` and `decisionRequests`); keep those helpers working.
